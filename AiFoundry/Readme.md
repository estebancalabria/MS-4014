# Azure AI Foundry – Guía Didáctica

## 🧠 ¿Qué es Azure AI Foundry?

**Azure AI Foundry** es una plataforma integrada diseñada para desarrolladores y equipos de IT que permite **diseñar, personalizar y gestionar aplicaciones y agentes de inteligencia artificial** en un solo lugar.

Permite crear experiencias avanzadas como chats inteligentes que:

* Interpretan texto e imágenes
* Responden de forma contextual
* Generan contenido visual
* Interactúan de forma más “humana”

---

## 🚀 Capacidades principales

### 1. Diseño con múltiples modelos de IA

Azure AI Foundry ofrece un **catálogo con más de 1800 modelos**, incluyendo:

* Modelos avanzados de Azure OpenAI
* Modelos livianos (familia Phi de Microsoft)
* Modelos de terceros:

  * Meta
  * Mistral
  * Cohere
  * Hugging Face
* Modelos específicos por tarea o industria

👉 Esto permite elegir el modelo más adecuado según el caso de uso.

---

### 2. Creación y personalización de agentes

Incluye una **toolchain completa para agentes de IA**:

* Servicio: **Azure AI Agent Service**
* Permite:

  * Crear agentes inteligentes
  * Conectarlos a múltiples fuentes de datos
  * Mejorar la calidad de las respuestas (grounding)

#### 🔗 Fuentes de conocimiento soportadas:

* Microsoft Fabric
* Microsoft Bing
* Azure AI Search

👉 Resultado: agentes más precisos y con contexto real.

---

### ⚙️ Automatización y acciones

Los agentes pueden ejecutar acciones mediante:

* **Azure AI Logic Apps**

Esto permite:

* Automatizar flujos de trabajo
* Orquestar procesos complejos
* Tomar decisiones automáticamente

---

### 3. Seguridad y IA responsable

Azure AI Foundry incorpora **seguridad por defecto** con:

#### 🛡️ Azure AI Content Safety

* Filtrado de contenido inapropiado (entrada y salida)
* Configuración personalizada de filtros
* Detección de:

  * Contenido sensible
  * Material protegido

#### 🔍 Otras capacidades:

* **Groundedness detection**: asegura que las respuestas se basen en fuentes confiables
* **Prompt shields**: protección contra ataques de prompt injection

---

### 4. Monitoreo y observabilidad

Incluye herramientas para gestionar aplicaciones en producción:

* Evaluaciones continuas
* Monitoreo de rendimiento
* Gobernanza

#### 📊 Métricas disponibles:

* Precisión (accuracy)
* Groundedness
* Equidad (fairness)
* Vulnerabilidad a ataques

👉 Permite mejorar continuamente la calidad del sistema.

---

### 🏢 Gestión centralizada

El **Management Center** ofrece:

* Administración centralizada
* Control de recursos
* Seguridad y compliance
* Simplificación de operaciones IT

Azure AI Foundry permite construir aplicaciones de IA completas combinando:
