# MS-4014 - Módulo 2: Agentes en Microsoft

## 🧠 Introducción

Este módulo explora el ecosistema de agentes de inteligencia artificial de Microsoft y ayuda a comprender cuándo adoptar, extender o construir soluciones de agentes personalizadas según el escenario, los objetivos de negocio y el nivel de madurez técnica.

---

## 🎯 Objetivos de aprendizaje

Al completar este módulo, deberías poder:

- Identificar los casos de uso principales de Microsoft 365 Copilot, Copilot Chat y agentes de primera parte.
- Describir las opciones para personalizar y extender Microsoft 365 Copilot.
- Identificar escenarios donde es adecuado construir agentes de IA personalizados o aplicaciones de IA generativa.
- Reconocer las herramientas de desarrollo disponibles en el ecosistema Microsoft.
- Evaluar la mejor estrategia de adopción, extensión o construcción según el caso de uso.

---

## 🌐 Ecosistema de agentes de Microsoft AI

### 📌 Visión general

Microsoft ofrece un ecosistema flexible que cubre desde productividad inmediata hasta soluciones avanzadas de IA generativa.

Permite:

- Mejorar la productividad
- Transformar procesos de negocio
- Crear aplicaciones inteligentes personalizadas

---

## 🧭 Tres enfoques principales

### 🟢 Adoptar
Uso de soluciones listas para usar:
- Microsoft 365 Copilot
- Copilot Chat
- Agentes integrados

👉 Objetivo: productividad inmediata sin configuración.

---

### 🟡 Extender
Personalización de Copilot con:
- Conectores de datos
- Agentes declarativos
- Lógica de negocio personalizada

👉 Objetivo: adaptar Copilot a procesos empresariales.

---

### 🔵 Construir
Creación de soluciones completamente personalizadas:
- Agentes avanzados
- Aplicaciones de IA generativa
- Modelos propios y orquestación avanzada

👉 Objetivo: control total y máxima flexibilidad.

---

## 🚀 Microsoft 365 Copilot, Copilot Chat y agentes

### 🧑‍💼 Microsoft 365 Copilot

Integrado en Word, Excel, Outlook, PowerPoint y Teams.

#### Capacidades:
- Redacción y resumen de contenido
- Análisis de datos
- Automatización de tareas
- Resumen de reuniones

---

### 💬 Copilot Chat

Interfaz conversacional para interactuar con IA.

#### Capacidades:
- Responder preguntas con GPT-4o
- Analizar archivos
- Generar contenido e imágenes
- Usar Microsoft Graph (con licencia Copilot)

---

### 🤖 Agentes de Copilot

Asistentes de IA dentro de Microsoft 365.

- Automatizan tareas
- Responden preguntas
- Se integran con datos organizacionales

#### Tipos:
- Integrados en Microsoft 365 Copilot
- Agentes personalizados

---

### 🧩 Agentes predefinidos

- Facilitador de reuniones
- Intérprete en tiempo real
- Project Manager en Planner
- Autoservicio de empleados
- Agentes de SharePoint

---

### 🌐 Otras experiencias Copilot

- GitHub Copilot
- Security Copilot
- Copilot en Azure
- Copilot en Dynamics 365
- Copilot en Power Platform
- Copilot en Windows

---

### 👥 Agentes por rol

- Ventas (CRM + análisis de oportunidades)
- Servicio (automatización de soporte)
- Finanzas (ERP + análisis financiero)

## 🔧 Personalización y extensión de Copilot

### 🚀 Beneficios

- Integración de datos externos
- Menor cambio de contexto
- Automatización empresarial
- Mejora de productividad

---

### 🔌 Conectores de Copilot

Permiten conectar datos externos a Microsoft 365.

#### Ejemplos:
- Salesforce
- ServiceNow
- Confluence
- Google services
- Box

👉 También se pueden crear conectores personalizados.

---

### 🤖 Agentes declarativos

Basados en Microsoft 365 Copilot.

#### Componentes:
- Instrucciones en lenguaje natural
- Conectores y fuentes de datos
- Acciones y plugins

#### Capacidades:
- Flujos de trabajo guiados
- Acceso a datos empresariales
- Automatización conversacional

---

### 🧠 Agentes personalizados

Soluciones avanzadas con control total.

#### Características:
- Modelos y lógica propios
- Orquestación avanzada
- Multi-agente
- Experiencia de usuario personalizada

#### Herramientas:
- Copilot Studio
- Teams SDK
- Microsoft 365 Agents Toolkit

---

### 🛠️ Opciones de desarrollo

- Copilot Studio (lite y full)
- SharePoint Agents
- Visual Studio Code
- Microsoft 365 Agents Toolkit
