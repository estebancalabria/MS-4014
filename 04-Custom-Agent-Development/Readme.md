# 04 - Custom Agents & Generative AI Solutions

## 📖 Introducción

En este módulo exploramos el ecosistema de tecnologías de Microsoft para construir agentes personalizados y soluciones de Inteligencia Artificial Generativa empresariales.

Microsoft ofrece múltiples enfoques para desarrollar agentes de IA, desde herramientas low-code orientadas a productividad empresarial hasta plataformas avanzadas para arquitecturas multiagente y soluciones enterprise altamente personalizadas.

A medida que las organizaciones buscan automatizar procesos, integrar sistemas propietarios y crear experiencias inteligentes, los agentes personalizados se convierten en un componente central de las soluciones modernas de IA.

# ⚠️ Agentes declarativos vs agentes personalizados

Antes de construir un agente completamente personalizado, Microsoft recomienda evaluar si el escenario puede resolverse mediante:

* Microsoft 365 Copilot
* Agentes declarativos
* Extensiones low-code

Los agentes declarativos permiten:

* Agregar lógica empresarial
* Integrar datos organizacionales
* Automatizar procesos
* Extender Copilot rápidamente

Sin embargo, para escenarios más avanzados como:

* Multiagente
* Integraciones complejas
* Arquitecturas enterprise
* UX altamente personalizada
* Modelos IA propios
* Orquestación avanzada

Es recomendable utilizar enfoques personalizados.
